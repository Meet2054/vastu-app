## Security Layers

```
┌─────────────────────────────────────────────────────────────┐
│                    SECURITY LAYERS                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  Layer 1: Authentication                                     │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  • Email/Password (Supabase Auth)                      │ │
│  │  • JWT tokens                                          │ │
│  │  • Auto-refresh (secure)                               │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Layer 2: Activation Control                                 │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  • One-time activation keys                            │ │
│  │  • Keys marked as used                                 │ │
│  │  • Cannot reuse keys                                   │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Layer 3: Device Binding                                     │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  • Hardware-based fingerprint                          │ │
│  │  • Machine ID + OS + CPU                               │ │
│  │  • SHA-256 hashed                                      │ │
│  │  • Verified on each app open                           │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Layer 4: Database Security (RLS)                            │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  • Row Level Security enabled                          │ │
│  │  • Users see only own data                             │ │
│  │  • Admin via service role only                         │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
│  Layer 5: Edge Function Validation                           │
│  ┌────────────────────────────────────────────────────────┐ │
│  │  • Server-side validation                              │ │
│  │  • Atomic operations                                   │ │
│  │  • Rollback on failure                                 │ │
│  └────────────────────────────────────────────────────────┘ │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## Data Flow: Activation Process

```
Step 1: User Login
┌────────┐    email/pass    ┌──────────┐
│  App   │ ───────────────> │ Supabase │
│        │ <─────────────── │   Auth   │
└────────┘     JWT token    └──────────┘

Step 2: Check Profile
┌────────┐   get profile    ┌──────────┐
│  App   │ ───────────────> │ Database │
│        │ <─────────────── │ profiles │
└────────┘  is_active=false └──────────┘

Step 3: Show Activation
┌────────────────────┐
│ Activation Screen  │
│ User enters key    │
└────────────────────┘

Step 4: Get Device FP
┌────────┐   invoke    ┌──────────┐
│  App   │ ─────────> │  Rust    │
│  (TS)  │ <───────── │ Backend  │
└────────┘  fingerprint└──────────┘

Step 5: Call Edge Function
┌────────┐      POST      ┌──────────────┐
│  App   │ ─────────────> │ Edge Func    │
│        │  {key, fp, id} │ activate-    │
│        │                │ device       │
└────────┘                └──────┬───────┘
                                 │
                                 ▼
                    ┌────────────────────┐
                    │  Validate Key      │
                    └────────┬───────────┘
                             ▼
                    ┌────────────────────┐
                    │  Register Device   │
                    └────────┬───────────┘
                             ▼
                    ┌────────────────────┐
                    │  Mark Key Used     │
                    └────────┬───────────┘
                             ▼
                    ┌────────────────────┐
                    │  Activate Profile  │
                    └────────┬───────────┘
                             ▼
┌────────┐  success  ┌──────────────────┐
│  App   │ <──────── │  Return Success  │
└────┬───┘           └──────────────────┘
     │
     ▼
┌─────────┐
│ Reload  │
│ & Login │
└─────────┘
```
